# SmartCart Frontend

Basic React frontend built for the provided Spring Boot SmartCart backend.

## Run
1. Open this folder in VS Code.
2. Use Command Prompt terminal if PowerShell blocks npm.
3. Run `npm install` once (internet required).
4. Run `npm run dev`.
5. Open http://localhost:5173

Backend should run on http://localhost:8080.
Vite proxies `/api` requests to the backend.
